# 命理分析工具（网页版）

上传截图 / 照片即可分析，支持**六模块 + 对话追问 + 实时联网**。纯本机运行，零依赖（不需要 npm install）。

## 快速开始

双击 **`启动.bat`**，浏览器会自动打开 `http://127.0.0.1:8756`。

或命令行：

```bat
node server.js
```

## 手机访问（同一 Wi-Fi）

服务默认监听 `0.0.0.0`，启动时控制台会打印局域网地址，**网页顶部也会显示**。手机连同一个 Wi-Fi，浏览器直接输入该地址即可（例如 `http://192.168.2.141:8756`）。

- 首次可能被 Windows 防火墙拦截：已自动尝试添加放行规则；若仍打不开，到「Windows 安全中心 → 防火墙 → 允许应用通过」放行 Node.js，或手动放行 8756 端口。
- 手机端同样支持拍照/相册上传（浏览器文件选择）。
- 电脑 IP 变了地址就变，以页面顶部那条绿色提示为准。

## 手机流量访问（公网穿透）

不在同一 Wi-Fi 也能用。双击 **`穿透.bat`**，它会：

1. 确保本地 `server.js` 在跑；
2. 用 `tools/cloudflared.exe` 建一条 Cloudflare 免费隧道；
3. 窗口里打印公网地址，形如 `https://xxxx-xxxx-xxxx.trycloudflare.com`。

手机用 4G/5G 访问：

```
https://xxxx-xxxx-xxxx.trycloudflare.com/?t=口令
```

口令在 `config.json` 的 `accessToken` 里（默认 `bz7f3c9a1e5b2d`）。**必须带 `?t=`**，否则接口会返回 401。

注意事项：
- 免费隧道**每次重启地址都会变**，以窗口打印为准；
- 无可用性保证（Cloudflare 免费 quick tunnel），断开就重开；
- 电脑必须保持开机、`穿透.bat` 窗口不能关；
- 隧道地址相当于"公开网址"，**不要发到群里**；口令一旦泄露，改 `config.json` 里的 `accessToken` 并重启即可；
- 想长期稳定、私有访问，可改用 Tailscale（电脑和手机各装一个，走私有网络，不暴露公网）。

## 功能一览（七项）

| 模块 | 输入 | 输出 |
|---|---|---|
| **八字** | 问真八字等排盘截图，或手动填四柱 | 排盘/十神/五行/格局/喜用 + **三条验证** + 详细运势 + 专项分析 |
| **紫微斗数** | 文墨天机/问真紫微命盘截图 | 命盘要点/命宫/身宫/十二宫/四化/格局/大限 |
| **面相** | 正面人脸照片 | 三停/五官/十二宫/气色/运势倾向 |
| **手相** | 手掌照片 | 掌形/生命线/智慧线/感情线/事业线 |
| **住宅风水** | 户型图或房屋照片 + 朝向 | 缺角/门冲/厨卫/财位 + 具体化解建议 |
| **占卜** | 直接输入问题 | 程序按当前时间起**梅花卦**（本卦/互卦/变卦/体用）+ 断语与应期 |
| **生时校正** | 三柱 + 已知重大事件 | 12 个候选时辰的确定性打分排序 + 最可能时辰与理由 |

每个模块出结果后，下方都有**「继续问」对话框**，可以一问一答追问，例如"我今年几月换工作最有利？""适合做哪类行业？"。

## 生时校正（定时辰）

很多人只知道年月日、不知道具体时辰。时辰不能直接"算"出来，只能**比较哪个时辰能解释更多已发生的事**。

用法：
1. 在「八字」模块识别出**年柱 / 月柱 / 日柱**（时辰不确定没关系）；
2. 切到「生时校正」，填入三柱、出生公历年、性别；
3. 候选时辰默认全选 12 个（若已知大致时段可只留几个）；
4. 添加**已知重大事件**（如 2016 结婚、2018 换工作、2024 破财），类型可选 11 种；
5. 程序对每个候选时辰计算确定性命中分，再让模型给出结论与置信度。

打分依据（全部可解释）：
- 时支被**流年 / 大运**冲、合、刑、害（说明该年有时柱应事）；
- 时干十神与该类事件是否对应（婚恋看官杀/财，生育看食伤，学业看印枭，破财看劫比）；
- **喜忌契合**：吉事是否落在喜神年、凶事是否落在忌神年（这一项让不同时辰真正拉开差距，因为时辰会改变旺衰与喜忌）；
- 婚恋/生育类额外看时支与日支（夫妻宫）的关系。

注意：分数接近时程序会如实说明"无法锁定"，并给出可自查的细节（兄弟姐妹数、头胎性别等）。**这不是精确科学**，仅供缩小范围。

## 技术架构

```
浏览器（public/index.html）
   │  图片 base64
   ▼
Node 后端（server.js，零依赖）
   ├─ 视觉识别 → 中转站视觉模型（opencode-go / deepseek-v4.1-flash）
   ├─ 确定性引擎（lib/bazi.js）→ 十神/藏干/五行/刑冲合害/旺衰/格局/大运/流年/十二长生
   ├─ 命理分析 → DeepSeek 官方 API（deepseek-v4-pro）
   └─ 对话追问 → DeepSeek 官方 API
```

**设计要点：数据由程序算，模型只负责解读。**
干支、十神、五五行占比、大运、卦象这些事实全部由代码按传统规则推算后作为「事实清单」喂给模型，并硬性要求逐字照抄，避免模型臆造。

## 识别精度保障（重要）

截图 OCR 最容易在**字形相近的干支**上出错（「己」被读成「乙」）。本工具用三重校验兜底：

1. **六十甲子合法性**：`乙卯` 这类不存在的组合直接判为识别错误并提示重填；
2. **五虎遁校验月干**：月干由年干 + 月支唯一决定，不符则自动修正并提示；
3. **五鼠遁校验时干**：时干由日干 + 时支唯一决定，不符则自动修正并提示；
4. **时柱 vs 出生时间**：由公历时间推时辰地支，与识别出的时柱比对，不一致则告警。

## 关于速度

`deepseek-v4-pro` 与中转站视觉模型都是**推理模型**，思维链会消耗大量 token：
- 视觉识别：30-90 秒（预算不足时自动加倍重试）
- 深度分析：2-4 分钟

页面上有实时进度提示，请耐心等待。

## 配置

编辑 `config.json`：

```json
{
  "port": 8756,
  "vision":   { "baseURL": "...", "apiKey": "...", "model": "deepseek-v4.1-flash" },
  "analysis": { "baseURL": "...", "apiKey": "...", "model": "deepseek-v4-pro", "maxTokens": 16000 }
}
```

- `vision`：必须支持视觉（读图），DeepSeek 官方 key **不支持**视觉，所以用的是中转站模型；
- `analysis`：DeepSeek 官方 key，负责文字分析；
- `maxTokens` 必须足够大（≥16000），否则思维链会把正文挤没。

也可用环境变量覆盖：`VISION_API_KEY` / `ANALYSIS_API_KEY` / `PORT`。

## 隐私与费用

- 全在本机运行，只有图片会发往模型接口用于识别，不上传其他数据。
- 每次八字深度分析约消耗 1.2-1.4 万 token（含思维链），按 DeepSeek 官方价约几分钱；视觉识别走中转站额度。
- `config.json` 里有明文 key，**不要把这个目录或端口暴露到公网**。
